==============================================================================
(A) NS scaling: invariance of M*T and Re_E
==============================================================================
  ell_lam/ell           = 1/lambda    (expect 1/lambda)
  Re_E(lam)/Re_E        = 1    (expect 1)
  Re_E as E,M,nu        = E**(2/5)*M**(1/5)/nu   (expect E**(2/5)*M**(1/5)/nu)
  (M*T)_lam/(M*T)       = 1    (expect 1)

==============================================================================
(B) the implicit -> explicit bootstrap:  (b) implies (c).
    (b) M*s*(1+log+(E0^(2/5)M^(1/5)/nu)) >= c1
    (c) M >= cc/(s*(1+log+(E0^(2/5)/(nu*s^(1/5)))))   with cc=min(c1,1)
    Search for a counterexample: (E0,nu,s,c1,M) with (b) true and (c) false.
==============================================================================
  samples                 = 4000000
  (b) true                = 2053207
  (b) true and (c) false  = 0    <-- must be 0

  Same search with cc replaced by c1 (i.e. WITHOUT the min(c1,1) guard):
  (b) true and (c-no-min) false = 11   <-- expected > 0: the guard is needed

==============================================================================
(C) the classical comparator: Leray/Giga  ||u(t)||_inf >= c nu^(1/2)(T-t)^(-1/2)
    fed through  ||u||_inf <= C E^(1/5) M^(3/5)   (Astra pass 8, eq. (4))
==============================================================================
  exponent of nu   = 5/6   (from (3/5)a = 1/2)
  exponent of E    = -1/3
  exponent of (T-t)= -5/6
  check E^(1/5)*(that)^(3/5) = sqrt(nu)/sqrt(s)   (expect nu^(1/2)/s^(1/2))
  => classical route gives exponent 5/6 in (T-t); the corollary gives 1 minus a log.

==============================================================================
(D) accumulation of vorticity implied by the corollary (compare BKM / Ingimarson-Kukavica)
==============================================================================
  claimed antiderivative F(r) = -5c*log(1 + log K - (1/5)log r)
  F'(r) - integrand           = 0   (expect 0)
  => int_?^t ||omega|| ds >= 5*c*log( 1 + log K + (1/5)log(1/(T-t)) ) + O(1)
  i.e.  >= 5*c*loglog(1/(T-t)) + O(1).
  Ingimarson-Kukavica (Euler, Thm 2.1): int_0^t ||omega|| >= (1/C) loglog(1/(T*-t)).
