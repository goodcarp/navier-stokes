absolute row sum. ∎

## 4. The kernel, and a representation with no principal value

**Lemma 4.1 (kernel constants).  EXACT (`k1` §B).**  With `G₅(x) = 1/(8π²|x|³)` the fundamental
solution of `−Δ₅` (`|S⁴| = 2π^{5/2}/Γ(5/2) = 8π²/3`, and `−|S⁴|R⁴ dG₅/dR = 1`),

```
  K(w) := −∂_z G₅(w) = 3 w_z/(8π²|w|⁵) ,    a = K * η ,
  |K(w)| ≤ C_K |w|^{-4} ,       C_K = 3/(8π²) = 0.0379954439 ,     C_K·|S⁴| = 1   EXACTLY
  |∇K(w)| = (3/(8π²))√(1+15ŵ_z²)/|w|⁵ ≤ C_{∇K}|w|^{-5} ,  C_{∇K} = 3/(2π²) = 0.1519817755 ,
                                                          C_{∇K}·|S⁴| = 4   EXACTLY
  ∫_{S⁴} ∇K dΩ = 0        (because ⟨ŵ_zŵ_j⟩_{S⁴} = δ_{jz}/5)
```

**Lemma 4.2 (no-PV representation).  PROVED.**  Let `g := ∇η` (a vector-valued measure; `η` has
compact support and bounded variation).  Then for every `d > 0`

```
  ∇a = K * g   (one integration by parts; absolutely convergent, |K| ~ |w|^{-4} in ℝ⁵)      (4.1)

  ∂_j∂_k a(x) =  ∫_{|w|<d} K(w) ∂_j g_k(x−w) dw
               + ∫_{|w|>d} (∂_jK)(w) g_k(x−w) dw
               + ∮_{|w|=d} K(w) ŵ_j g_k(x−w) dS(w) .                                       (4.2)
```
*Proof of (4.2).*  Split `F := K*g` at `|w| = d`.  On `|w| < d` differentiate under the integral
(legitimate: `K ∈ L¹_loc`, `g ∈ C¹` on `B(x,d)` by (1.1)).  On `|w| > d` write
`∂_{x_j}g_k(x−w) = −∂_{w_j}[g_k(x−w)]` and integrate by parts over `Ω = \{|w|>d\}`, whose outward
normal is `−ŵ`; the boundary term is `+∮_{|w|=d}K ŵ_j g_k dS`.  Both bulk integrals converge
absolutely (`|∂_jK| ~ |w|^{-5}`, and `|g|` has the shell decay of (2.1)). ∎

**Corollary 4.3 (the two bounds).  PROVED.**  With
`Λ_p(x,d) := ∫_{|x−x'|>d}|x−x'|^{-p}d|Dη|(x')` and `C_K|S⁴| = 1`,

```
   |∇a(x)|       ≤  d · sup_{B(x,d)}|∇η|  +  C_K Λ₄(x,d)                                  (4.3)
   ‖∇²a(x)‖_op   ≤  d · sup_{B(x,d)}‖∇²η‖_F  +  sup_{∂B(x,d)}|∇η|  +  C_{∇K} Λ₅(x,d)      (4.4)
```
*Proof.*  For (4.3): `∫_{|w|<d}|K| ≤ C_K|S⁴|∫_0^d s^{-4}s⁴ds = d`.  For (4.4): the same for the
first term with `‖·‖_F ≥ ‖·‖_op`; the second term is `‖u⊗v‖_F = |u||v|` under the integral; the
surface term is `≤ C_K d^{-4}·|S⁴|d⁴·sup_{∂B}|∇η| = sup_{∂B}|∇η|`. ∎

**Remark 4.4 (why the surface term is free).**  `C_K|S⁴| = 1` exactly, so the price of the
integration-by-parts boundary is *exactly* `sup_{∂B(x,d)}|∇η|`, with no constant.  For the
plateau that is `M/R_-²`.

## 5. The datum's total variation, and the absence of a log

**Lemma 5.1 (the shell density).  PROVED, and computed.**  Write `η = −M 𝔥(t) Θ(ρ)/ρ` with
`𝔥(t) = A(t)/√(1−t²)`, `A` the angular profile of `ω^θ` and `t = cos φ`.  Where `Θ ≡ 1`,
`|∇η| = (M/ρ²)√(𝔥² + (1−t²)𝔥'²)`; with `dΩ₄ = sin³φ dφ dΩ₃ = (1−t²)dt · dΩ₃` and `|S³| = 2π²`,

```
  |Dη|({ρ'<|x'|<ρ'+dρ'}) = M ρ'² 𝒥 dρ' ,
  𝒥 = 𝒥_ac + 𝒥_jump ,
  𝒥_ac   = |S³| ∫_{-1}^{1} √( 𝔥(t)² + (1−t²)𝔥'(t)² ) (1−t²) dt ,
  𝒥_jump = 2|S³| · 𝔥(0⁺)          (the equatorial jump: [η] = 2M𝔥(0⁺)/ρ' on the 4-plane {z=0},
                                   and ∫_{ρ'<|y|<ρ'+dρ'} (2M𝔥(0⁺)/|y|) d⁴y = 2M𝔥(0⁺)|S³|ρ'²dρ') .
```
The point of principle: **a jump surface through the origin has exactly the same `ρ'²dρ'` shell
density as the smooth bulk**, because `∫_{ρ'<|y|<ρ'+dρ'} (2M/|y|)d⁴y = 2M|S³|ρ'²dρ'`.  So a
sharp `sgn(z)` costs nothing in the far integrals, and a layer of angular width `δ_m` costs
`(steepness 1/δ_m) × (thickness δ_m) = O(1)`.  **This is why `δ_m` drops out.**

**Lemma 5.2 (no log).  PROVED.**  Under (2.1), for `x` with `|x| = ρ`,

```
  ∫_{ρ'>2ρ} |x−x'|^{-4} d|Dη| ≤ 16 M𝒥 ∫_{2ρ}^∞ ρ'^{-2}dρ' = 8 M𝒥/ρ ,
  ∫_{ρ'<ρ/2} |x−x'|^{-4} d|Dη| ≤ 16 ρ^{-4} M𝒥 (ρ/2)³/3 = (2/3) M𝒥/ρ ,
  ∫_{ρ'>2ρ} |x−x'|^{-5} d|Dη| ≤ 32 M𝒥 ∫_{2ρ}^∞ ρ'^{-3}dρ' = 4 M𝒥/ρ² ,
  ∫_{ρ'<ρ/2} |x−x'|^{-5} d|Dη| ≤ 32 ρ^{-5} M𝒥 (ρ/2)³/3 = (4/3) M𝒥/ρ² ,
```
using `|x−x'| ≥ ρ'/2` on the first region and `≥ ρ/2` on the second.  **Both are `O(1)` in
`R/ρ₀`: there is no `log`.**  The collar `ρ/2 < ρ' < 2ρ` is the only part that sees the geometry;
it is evaluated by quadrature in `k3` (§8), and it is finite because `|x−x'| ≥ d` there.

**Remark 5.3 (where the log went).**  `a` itself is `≍ (M/2)L`.  By
`rebuild/far-near-kernel-lemma` §1 Consequence A the `l = 1` interior mode of every outer shell
is **exactly constant inside that shell**, so the whole `M L` is an `x`-independent additive
constant accumulated over `dρ'/ρ'`, and it is annihilated by one derivative.  Lemma 5.2 proves
the same fact without the modal decomposition: the log lives in `a`, never in `∇a` or `∇²a`.
This is the sharp form of V-b §7 remark 1 ("the `O(M log)` part contributes nothing to `K₂`").

## 7. Time propagation

`η` is a genuine scalar on `ℝ⁵` obeying `∂_tη + b·∇₅η = νΔ₅η` with the *full* 5-D Laplacian, so
`∂_j` commutes with `Δ₅` and

```
   D_t(∂_jη)     = −(∂_j b)·∇η + νΔ₅(∂_jη)                                                (7.1)
   D_t(∂_i∂_jη)  = −(∂_i∂_j b)·∇η − (∂_i b)·∇∂_jη − (∂_j b)·∇∂_iη + νΔ₅(∂_i∂_jη)          (7.2)
```

**Lemma 7.1 (global gradient propagation).  PROVED.**  From (7.1) and the parabolic maximum
principle, `‖∇η(·,t)‖_∞ ≤ e^{∫₀^tΓ}‖∇η₀‖_∞`, and `∫₀^τΓ = 2log(3/2)` (V-b §1 window constants),

## 16. One-paragraph summary

`‖∇²₅b‖` is built from `a`, `∇a`, `∇²a` (nonlocal) and `η`, `∇η` (local at the point) — never
from `∇²η`.  `∇a = K*∇η` with `K` of degree `−4`, and the datum's total-variation measure has
shell density `Mρ'²𝒥`, so the far integrals converge at both ends with no `log(R/ρ₀)`: the whole
`ML` of the strain sits in the `l = 1` interior mode, which is exactly affine and invisible to a
second derivative.  What is left is a purely local question — how close the evaluation point is
to the three places where `η` is not smooth.  The equatorial jump and the axis taper are far
away at `φ₀ = 30°` and stay far away over `λ ∈ [1,3/2]` (distances shrink by at most `4/9`); the
inner radial edge is *not* far away at `f = 0`, and if it is sharp it makes `K₂` infinite.  With
the campaign's own `tanh` radial mollification the answer is `K₂ ≤ 161.77 M/ρ₀` proved and
`5.39 M/ρ₀` measured over the whole window, uniformly in `L`.  That closes the single item V-b listed as open, and it
does not rescue V-b, because the terms the refuter found are the ones that bind.
